# Ripo

Gestionale di magazzino per la rete interna: assegna le scorte agli ordini non ancora evasi o spediti, dal più
vecchio al più recente, e identifica gli articoli in arrivo da barcode, codice stampato o immagine.

«Ripo» è il nome per ora (decisione 386 in `docs/decisioni.md`); il repository conserva il nome provvisorio DondEres
fino alla fine della prova visiva (decisione 431). Regole del progetto: `AGENTS.md`. Specifica: `docs/architettura.md`.
